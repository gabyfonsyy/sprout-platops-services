Platform Operations Services — How It Works

This portal covers paid backend services for active clients: data migrations, database operations, configuration changes, and other work not covered by standard BAU. All requests go through a structured review, costing, and approval process before any work begins.

01 — Overview
What qualifies as a Platform Operations service request?

A Platform Operations service request covers backend work for active clients that requires direct database access, system-level configuration changes, or manual data operations — and where a service fee applies.

These are not standard BAU tickets. Every request is reviewed for feasibility, scoped, priced, and requires a signed Work Order before execution. Fee waivers require written CTO approval.

If you are unsure whether your request falls under this portal, reach out to the Platform Operations team before submitting.
